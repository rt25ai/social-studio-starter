# Social Studio Starter

ערכה של RT-AI שמכינה מחשב Windows או Mac לעבודה עם Claude Code על רילים, סרטונים, קרוסלות ודפי נחיתה במיתוג של העסק.

## הורדה

**[הורדת הקיט (ZIP)](https://github.com/rt25ai/social-studio-starter/releases/latest/download/Social_Studio_Starter.zip)** - הגרסה האחרונה, בלי התחברות.

מחלצים את הקובץ לתיקייה קצרה (למשל `C:\Studio`) ופותחים את `START.cmd` ב-Windows או `START_MAC.command` ב-Mac.

- מדריך ההקמה: [setup-guide-he.md](https://github.com/rt25ai/social-studio-starter/releases/latest/download/setup-guide-he.md)
- הפרומפט הראשון: [01-first-session.md](https://github.com/rt25ai/social-studio-starter/releases/latest/download/01-first-session.md)
- דף הקיט: https://claude.ai/artifact/Utdshx5eRxPXsinCJCWLxu
- ה-SHA-256 של כל גרסה כתוב בעמוד ה-Release שלה.
